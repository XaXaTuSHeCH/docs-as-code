# Классификатор обращений в техническую поддержку

## Описание

Система получает текст обращения и определяет его категорию с помощью ИИ-агента для направления соответствующей группе специалистов. Это помогает быстрее передавать вопрос нужной команде и сокращает ручную сортировку заявок.

## Пользователи

- **Пользователь** — отправляет обращение и получает ответ.
- **Оператор поддержки** — проверяет категорию и группу, при необходимости исправляет результат.
- **Специалист** — получает обращения и помогает пользователю решить вопрос.

## Основные функции

- приём и сохранение текста обращения.
- автоматическое определение категории и группы специалистов.
- передача неоднозначных обращений оператору для ручной обработки.
- просмотр и корректировка результата классификации оператором.

## Комплект документации

1. **Описание проекта** — для команды и заинтересованных лиц, чтобы понимать назначение системы и его пользователей.
2. **Требования** — для разработчиков и тестировщиков, чтобы согласовать ожидаемое поведение и критерии проверки.
3. **Архитектура системы** — для разработчиков и сопровождения, чтобы видеть компоненты сервиса и их взаимодействие.
4. **Документация API** — для разработчиков интеграций, чтобы отправлять обращения и получать результаты классификации.
5. **Документация ИИ-агента** — для ML-команды и операторов, чтобы понимать категории, входные данные, ограничения и правила передачи сомнительных результатов на ручную проверку.
